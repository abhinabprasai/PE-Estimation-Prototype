1. How Purchasing Orders Parts and Materials — The Daily Operating Loop 1. Demand intake. The buyer’s workbench opens on: PR queue (MRP-generated + reorder auto-PRs + manual), MRP 
exception messages assigned to buy items (EX-01/02/03/06), and the Expedite Board. Everything is bucketed by buyer code (items carry a Buyer assignment). 2. Source determination. 
For each PR line the system proposes the source: AVL preferred vendor → last PO price and lead time → open contract/blanket if one exists. Buyer accepts or overrides (override 
reason logged). No AVL vendor for a QI-critical item = hard block (E-PUR-02) → start AVL qualification or RFQ. 3. RFQ when needed. New items, expiring price agreements, or value > 
$25k without contract (policy) route through RFQ (§4): multi-vendor invite, sealed responses, comparison grid, award writes the new AVL price basis. 4. PO creation. PRs group into 
POs per vendor per lot-sizing (one PO, many lines; delivery schedules per line where staged deliveries are wanted). Approval workflow by value (ACC 22 engine): Buyer ≤ $25k, 
Purchasing Manager ≤ $250k, + Controller above, + CFO above $1M. 5. Transmission & confirmation. PO PDF (entity letterhead, terms, quality clauses, drawing attachments for 
fabricated parts) emails to vendor; vendor confirmation (date + qty per line) is captured — unconfirmed POs older than 3 business days surface on the workbench. 6. Expedite / 
de-expedite. MRP reschedule messages write suggestions onto the Expedite Board (§7); buyer actions become dated change requests to the vendor with full history. 7. Receipt & 
closure. GRN against PO (INV 5.1/5.6), QI per plan, three-way match (ACC 6), PPV/IPV visible in CVA (Part A §8). Lines close at full receipt + invoice; short-close with reason
